# Combat visuals and Hangar interaction direction

Target experience:

- every fire action produces a visible projectile from the actual weapon hardpoint to the target module;
- laser, missile, scatter and plasma have distinct motion and impact language;
- damaged Sensors / Engines visibly increase aiming instability; misses must use the same server-authoritative result on both PvP clients;
- impact, miss, fire and electrical status effects are presentation effects driven by server combat events;
- the Hangar is an interactive module constructor: select, move, install, remove and upgrade modules while keeping gameplay IDs stable;
- visual implementation remains separate from combat rules so effects and skins can be redesigned independently.
